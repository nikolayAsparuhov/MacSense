# Código

Archivos fuente de la mayoría de lenguajes y formatos de configuración populares. Útil para detectar capturas de proyectos antiguos, gists descargados o clones de repos obsoletos consumiendo disco.

## Detalles

Extensiones clasificadas como código: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build` y otros directorios de artefactos locales del proyecto no se separan — aparecen como código/archivos normales dentro del proyecto. La categoría Limpieza → Cachés de desarrollo apunta a las cachés *compartidas* fuera de tus proyectos.
