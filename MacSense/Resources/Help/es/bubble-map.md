# Mapa de burbujas

Los círculos interactivos en la pestaña Tamaño de Almacenamiento. Cada burbuja representa una carpeta; el área es proporcional al tamaño recursivo.

## Detalles

Cómo leerlo:

- **Círculo más grande = carpeta más grande.** Área bidimensional, no radio — una carpeta el doble de grande tiene aproximadamente el doble de área visible.
- **Pulsa una burbuja** para entrar en esa carpeta. El mapa de la derecha y la migaja superior se actualizan.
- **Riel de selección** a la izquierda permite marcar elementos para enviarlos a la papelera. Marcar aquí selecciona carpetas enteras.

Los hermanos pequeños se agrupan en una burbuja "Otros" para mantener legible la visualización. Pulsándola, la lista lateral se expande para mostrar cada entrada.

El layout se recalcula cuando cambia la migaja — sin animación entre layouts para que la navegación sea ágil.
