# Code

Source files across most popular languages and config formats. Useful for spotting old project snapshots, downloaded gists, or stale repo clones eating disk.

## Details

Extensions classified as code: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build`, and other project-local artifact directories aren't broken out separately — they show up as ordinary code/files inside their parent project. The Cleanup → Developer Caches category targets the *shared* package caches outside your projects.
