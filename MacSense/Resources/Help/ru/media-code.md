# Код

Исходные файлы в большинстве популярных языков и форматов конфигурации. Полезно для выявления старых проектов, скачанных gist'ов или устаревших клонов репозиториев, занимающих диск.

## Подробности

Расширения, классифицированные как код: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build` и другие локальные артефактные каталоги проектов не выделяются отдельно — они показываются как обычный код/файлы внутри родительского проекта. Категория Очистка → Кэши разработки нацелена на *общие* пакетные кэши вне ваших проектов.
