# Локальные снимки Time Machine

Часовые снимки уровня диска, которые Time Machine делает даже когда диск резервного копирования не подключён. Они живут на внутреннем диске и тихо потребляют место.

## Подробности

Time Machine ведёт скользящее окно локальных снимков, чтобы можно было восстановить недавние изменения без внешнего диска. Каждый снимок — это ссылка copy-on-write, поэтому новый снимок дёшев, но по мере правок и удалений снимки фиксируют эти байты на месте.

Признаки накопления:

- Диск кажется заполненным, но Finder показывает свободное место.
- «Очищаемые» байты велики.
- После большой загрузки её удаление не освобождает место.

MacSense вызывает `tmutil thinlocalsnapshots /` для их освобождения по требованию. macOS удаляет старейшие первыми; резервные копии Time Machine на внешнем диске не затрагиваются. После повторного подключения внешнего диска новые снимки накапливаются заново.
