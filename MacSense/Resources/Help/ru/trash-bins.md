# Корзины

Содержимое `~/.Trash` плюс корзины каждого тома (внешних дисков). MacSense очищает их, чтобы место действительно вернулось системе.

## Подробности

Перетаскивание файла в Корзину лишь помечает его на удаление — байты остаются на диске, пока Корзина не очищена. macOS показывает освобождённое место в Дисковой утилите, но считает его занятым до подтверждения.

Очистка MacSense:

- Перечисляет каждый файл в `~/.Trash` и на каждом смонтированном томе.
- Сообщает общий восстановимый размер.
- При очистке файлы удаляются окончательно.

Это единственная **необратимая** операция — после очистки файлов нет. Перед подтверждением просмотрите список.
