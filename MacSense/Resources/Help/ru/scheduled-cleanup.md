# Запланированная очистка

Опциональное повторяющееся сканирование в фоне с ежедневной, еженедельной или ежемесячной частотой, публикующее уведомление со сводкой.

## Подробности

При включении MacSense использует `NSBackgroundActivityScheduler` — энергоэкономичный API задач macOS — для запуска Smart Scan по выбранным категориям. Результат доставляется одним уведомлением:

> Найдено 4,7 ГБ восстановимых в 4 категориях. Откройте MacSense для проверки.

Касание уведомления открывает MacSense в разделе Очистка.

Важные ограничения:

- **Ничего не удаляется автоматически.** Расписание уведомляет; вы решаете, что (если вообще) чистить.
- **Расписание выполняется, пока MacSense открыт или недавно был активен.** macOS может откладывать фоновые задачи. Никаких LaunchAgent или демонов — закрытие приложения приостанавливает расписание до следующего запуска.

Разрешение на уведомления запрашивается один раз при первом запуске. Если вы отказали, раздел Расписания показывает баннер с ссылкой на Настройки системы.
