# Прочее

Файлы, не соответствующие ни одной из именованных медиа-категорий — кэши, данные приложений, частичные загрузки, файлы без расширения и проприетарные форматы.

## Подробности

Это «всё остальное». Большой итог в «Прочее» часто указывает на:

- Папки Application Support (`~/Library/Application Support/...`).
- Частичные загрузки с расширениями `.part` / `.crdownload`.
- Образы дисков, смонтированные из `.dmg`-файлов.
- Контейнеры sandbox и group containers.

Изучите крупные записи Прочего перед удалением — некоторые принадлежат активно используемым приложениям.
