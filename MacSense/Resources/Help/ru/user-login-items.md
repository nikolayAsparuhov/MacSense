# Пользовательские объекты входа

Приложения и помощники, запускающиеся автоматически при вашем входе в Mac. Принадлежат вашей учётной записи, поэтому отключение или удаление затрагивает только вашу сессию.

## Подробности

Пользовательские объекты входа поступают из двух источников:

- **plist-файлы launchd** в `~/Library/LaunchAgents` — обычно устанавливаются сторонними приложениями для фоновой синхронизации, проверки обновлений или элементов строки меню.
- **Регистрации `SMAppService`**, объявленные внутри бандла приложения (macOS 13+). MacSense показывает их, но не может переключать — используйте Настройки системы → Основные → Объекты входа.

Большинство пользовательских объектов входа можно безопасно отключить: родительское приложение продолжит работать, просто без автозапуска. Если что-то начнёт работать неправильно, повторное включение агента или переоткрытие приложения восстановит работу.
