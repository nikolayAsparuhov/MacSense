# Карта хранилища

Карта папка-за-папкой вашего диска, где каждый элемент масштабирован по реальному занятому месту. Позволяет найти, что съедает место, без догадок.

## Подробности

Раздел Хранилище строит дерево каждой папки под `/`, считает рекурсивные размеры и показывает два вида:

- **Вкладка «Размер»** — интерактивная пузырьковая карта. Большие круги = большие папки. Кликните, чтобы войти; хлебные крошки сверху отслеживают путь.
- **Вкладка «Тип»** — файлы, сгруппированные по типу медиа (видео, аудио, архивы, скриншоты и т.д.), чтобы вы видели, например, что 30 ГБ — это видеофайлы.

Первое сканирование занимает ~30 секунд, потому что обходится каждый байт под домашней папкой. После этого MacSense кэширует снимок на диск, чтобы последующие визиты сразу показывали данные, пока обновление идёт в фоне.

Файлы никогда не перемещаются и не удаляются из вида карты — это режим только чтения. Используйте листы категорий Очистки, когда хотите действительно отправить что-то в Корзину.
