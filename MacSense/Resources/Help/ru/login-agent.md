# Агент входа

Процесс, который macOS запускает автоматически при входе в систему. Некоторые необходимы (системные службы, помощники Связки ключей), другие — спутники приложений, которые не обязательно держать постоянно запущенными.

## Подробности

Агенты входа поступают из трёх источников:

- **Системные** — встроенные macOS-агенты в `/System/Library/LaunchAgents`. MacSense никогда их не трогает.
- **Пользовательские** — plist-файлы launchd в `~/Library/LaunchAgents`. Часто устанавливаются сторонними приложениями для фоновой синхронизации, проверки обновлений или элементов строки меню.
- **Встроенные** — зарегистрированные через `SMAppService` (см. «Встроенный объект входа»).

Пользовательские агенты можно безопасно отключить или удалить — родительское приложение продолжит работать, но потеряет фоновое поведение. Если что-то начнёт работать неправильно, повторная активация агента или переустановка приложения восстановит его.
