# Встроенный объект входа

Объект входа, зарегистрированный самим приложением через `SMAppService` (macOS 13+). Сторонние инструменты — включая MacSense — не могут отключить, изменить или удалить их по соображениям безопасности.

## Подробности

Apple ввела `SMAppService` для замены старых API объектов входа. Преимущества:

- Приложения регистрируются как агенты входа из собственного бандла.
- macOS гарантирует, что ничто извне приложения не может вмешиваться в регистрацию.
- Пользователь сохраняет полный контроль через Настройки системы.

Компромисс: инструменты вроде MacSense могут показывать эти регистрации, но не переключать их. Действие «Отключить» открывает **Настройки системы → Основные → Объекты входа** на нужной панели, чтобы вы переключили сами.

Старые объекты входа, зарегистрированные через прежние API (LSSharedFileList, plist-файлы launchd в `~/Library/LaunchAgents`), остаются управляемыми через MacSense.
