# Пузырьковая карта

Интерактивные кружки на вкладке «Размер» в Хранилище. Каждый пузырь представляет одну папку; площадь пропорциональна рекурсивному размеру папки.

## Подробности

Как читать:

- **Больше круг = больше папка.** Двумерная площадь, не радиус — папка вдвое большего размера имеет примерно вдвое большую видимую площадь.
- **Кликните по пузырю**, чтобы войти в папку. Пузырьковая карта справа и хлебные крошки сверху обновляются.
- **Полоса выбора** в левой боковой панели позволяет помечать элементы для отправки в Корзину. Пометка здесь выбирает целые папки сразу.

Маленькие соседние папки группируются в пузырь **«Прочие элементы»**, чтобы визуализация оставалась читаемой. Клик по нему разворачивает список боковой панели, чтобы показать каждую запись.

Раскладка пузырей пересчитывается при каждом изменении хлебных крошек — без анимации между раскладками, чтобы навигация оставалась резвой.
