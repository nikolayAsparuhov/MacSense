# Восстановимое пространство

Общее число байт, которое MacSense оценивает как возможное к возврату по всем категориям текущего Smart Scan.

## Подробности

Цифра в hero-блоке Очистки — это сумма:

- Системного мусора
- Пользовательского кэша
- Корзин
- Очищаемого пространства (локальные снимки TM + удаляемые файлы iCloud)
- Кэшей разработки

Сканирование не разрушительно — ничего не удаляется, пока вы не нажмёте «Очистить» в категории. Оценка использует размер, занятый на диске, ту же меру, которую macOS показывает в «Свойствах».

Числа слегка снижаются со временем, потому что macOS ротирует логи, освобождает кэши и записывает новые файлы. Повторный запуск Smart Scan обновляет оценку.
