# Espace récupérable

Total des octets que MacSense estime pouvoir vous rendre dans toutes les catégories du Smart Scan en cours.

## Détails

Le nombre dans le héros Nettoyage est la somme de :

- Fichiers système
- Cache utilisateur
- Corbeille
- Espace purgeable (instantanés TM locaux + fichiers évincables iCloud)
- Caches de développement

Une analyse n'est pas destructive — rien n'est supprimé tant que vous ne cliquez pas sur Nettoyer dans une catégorie. L'estimation utilise la taille allouée sur disque, la même mesure que dans « Lire les informations ».

Les chiffres baissent légèrement avec le temps car macOS rote les logs, évince les caches et écrit de nouveaux fichiers. Relancer Smart Scan rafraîchit l'estimation.
