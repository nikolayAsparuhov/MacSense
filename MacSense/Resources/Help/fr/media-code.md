# Code

Fichiers source dans la plupart des langages et formats de configuration populaires. Utile pour repérer d'anciens snapshots de projets, des gists téléchargés ou des clones de dépôts obsolètes.

## Détails

Extensions classées comme code : `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build` et autres répertoires d'artefacts locaux du projet ne sont pas séparés — ils apparaissent comme du code/fichiers ordinaires dans leur projet parent. La catégorie Nettoyage → Caches de développement vise les caches *partagés* en dehors de vos projets.
