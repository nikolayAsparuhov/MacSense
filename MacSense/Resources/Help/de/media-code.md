# Code

Quelldateien in den meisten gängigen Sprachen und Konfigurationsformaten. Nützlich, um alte Projekt-Snapshots, heruntergeladene Gists oder veraltete Repo-Klone zu erkennen, die Speicher fressen.

## Details

Als Code klassifiziert: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build` und andere projektlokale Artefaktordner werden nicht separat aufgeschlüsselt — sie erscheinen als gewöhnlicher Code/Dateien innerhalb des Projekts. Die Kategorie Cleanup → Entwickler-Caches zielt auf die *geteilten* Paket-Caches außerhalb deiner Projekte.
