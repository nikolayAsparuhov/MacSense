# Bubble-Karte

Die interaktiven Kreise im Tab Größe der Speicher-Sektion. Jede Bubble steht für einen Ordner; die Fläche ist proportional zur rekursiven Größe.

## Details

So liest du sie:

- **Größerer Kreis = größerer Ordner.** Zweidimensionale Fläche, nicht Radius — ein doppelt so großer Ordner hat etwa doppelt so viel sichtbare Fläche.
- **Klick auf eine Bubble** zoomt in diesen Ordner. Die Bubble-Karte rechts und die Brotkrume oben aktualisieren sich.
- **Auswahlleiste** links erlaubt das Markieren für den Papierkorb. Hier markieren wählt ganze Ordner aus.

Kleine Geschwister werden in einer „Andere Einträge"-Bubble gruppiert, damit die Visualisierung lesbar bleibt. Klick darauf erweitert die Seitenleiste mit jedem Eintrag.

Das Bubble-Layout wird neu berechnet, sobald die Brotkrume sich ändert — ohne Animation zwischen Layouts, damit die Navigation flott bleibt.
