# पुनर्प्राप्त करने योग्य स्पेस

कुल बाइट्स जिन्हें MacSense वर्तमान Smart Scan की हर श्रेणी में आपको लौटा सकता है, यह अनुमान।

## विवरण

Cleanup hero पर संख्या इनका योग है:

- सिस्टम जंक
- यूज़र कैश
- ट्रैश
- पर्जेबल स्पेस (Time Machine स्थानीय स्नैपशॉट + iCloud निष्कासन योग्य फ़ाइलें)
- डेवलपर कैश

स्कैन गैर-विनाशकारी है — जब तक आप किसी श्रेणी पर "Clean" नहीं दबाते, कुछ हटाया नहीं जाता। अनुमान डिस्क पर आबंटित आकार उपयोग करता है, वही माप जो macOS "Get Info" में उपयोग करता है।

संख्याएँ समय के साथ थोड़ी कम होती हैं क्योंकि macOS लगातार लॉग रोटेट करता है, कैश हटाता है, और नई फ़ाइलें लिखता है। Smart Scan फिर से चलाने से अनुमान ताज़ा होता है।
