# Time Machine स्थानीय स्नैपशॉट

घंटे-घंटे पर डिस्क-स्तरीय स्नैपशॉट जो Time Machine बैकअप ड्राइव के बिना भी लेता है। ये आपकी आंतरिक डिस्क पर रहते हैं और चुपचाप स्पेस लेते हैं।

## विवरण

Time Machine का आधुनिक डिज़ाइन स्थानीय स्नैपशॉट की एक रोलिंग विंडो रखता है ताकि आप बाहरी ड्राइव के बिना हाल के बदलाव बहाल कर सकें। हर स्नैपशॉट copy-on-write रिफरेंस है, इसलिए नया स्नैपशॉट सस्ता है — पर जैसे-जैसे आप संपादित और हटाते हैं, स्नैपशॉट उन बाइट्स को जगह पर बाँध देते हैं।

जमा होने के संकेत:

- डिस्क भरी लगती है पर Finder में मुक्त स्पेस दिखता है।
- "पर्जेबल" बाइट्स बड़े हैं।
- बड़ी डाउनलोड के बाद, उसे हटाने पर स्पेस मुक्त नहीं होता।

MacSense `tmutil thinlocalsnapshots /` चलाकर मांग पर रिलीज़ करता है। macOS पहले सबसे पुराने हटाता है; बाहरी Time Machine ड्राइव पर बैकअप अप्रभावित रहते हैं। आपके बाहरी ड्राइव को फिर जोड़ने पर ताज़ा स्नैपशॉट वापस आते हैं।
