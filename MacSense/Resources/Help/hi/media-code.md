# कोड

अधिकांश लोकप्रिय भाषाओं और कॉन्फ़िग प्रारूपों में स्रोत फ़ाइलें। पुराने प्रोजेक्ट स्नैपशॉट, डाउनलोड किए गए gist, या डिस्क खाने वाले बासी रेपो क्लोन को पहचानने के लिए उपयोगी।

## विवरण

कोड के रूप में वर्गीकृत एक्सटेंशन: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`।

`node_modules`, `target`, `build`, और अन्य प्रोजेक्ट-स्थानीय आर्टिफैक्ट डायरेक्टरी अलग नहीं किए जाते — वे अपने मूल प्रोजेक्ट के अंदर सामान्य कोड/फ़ाइल के रूप में दिखते हैं। Cleanup → Developer Caches श्रेणी आपके प्रोजेक्ट के बाहर *साझा* पैकेज कैश को लक्षित करती है।
