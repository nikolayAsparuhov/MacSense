# एम्बेडेड लॉगिन आइटम

ऐप द्वारा `SMAppService` (macOS 13+) के माध्यम से स्वयं रजिस्टर्ड एक लॉगिन आइटम। तृतीय-पक्ष टूल — MacSense सहित — सुरक्षा कारणों से इन्हें अक्षम, संशोधित या हटा नहीं सकते।

## विवरण

Apple ने पुराने लॉगिन आइटम API को बदलने के लिए `SMAppService` पेश किया। फ़ायदे:

- ऐप्स अपने ही bundle से स्वयं को लॉगिन एजेंट के रूप में रजिस्टर करते हैं।
- macOS गारंटी देता है कि ऐप के बाहर कुछ रजिस्ट्रेशन से छेड़छाड़ नहीं कर सकता।
- उपयोगकर्ता सिस्टम सेटिंग्स के माध्यम से पूर्ण नियंत्रण रखता है।

व्यापार-समझौता: MacSense जैसे टूल इन रजिस्ट्रेशन्स को दिखा सकते हैं पर टॉगल नहीं कर सकते। "Disable" क्रिया उचित पैनल पर **System Settings → General → Login Items** खोलती है ताकि आप स्वयं स्विच फ्लिप करें।

पुराने API (LSSharedFileList, `~/Library/LaunchAgents` में launchd plist) से रजिस्टर्ड पुराने लॉगिन आइटम MacSense से प्रबंधनीय रहते हैं।
