# 计划清理

可选的循环扫描,以每日、每周或每月的频率在后台运行,并发布摘要通知。

## 详情

启用时,MacSense 使用 `NSBackgroundActivityScheduler` — macOS 的能效友好任务 API — 对你勾选的类别执行 Smart Scan。结果以一条通知形式送达:

> 在 4 个类别中找到可恢复 4.7 GB。打开 MacSense 查看。

点按通知会打开 MacSense 至清理部分。

重要约束:

- **不会自动删除任何内容。** 计划只通知;由你决定要不要清理什么。
- **计划在 MacSense 打开或最近活跃时运行。** macOS 在重负载下可能延迟后台任务。没有 LaunchAgent 也没有守护进程 — 完全关闭应用会暂停计划,直到下次启动。

通知权限在首次启动时请求一次。如果之前拒绝了,计划部分会显示横幅,带有跳转到系统设置的快捷方式。
