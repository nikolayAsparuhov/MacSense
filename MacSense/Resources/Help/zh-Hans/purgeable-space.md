# 可清除空间

macOS 已认为可回收但尚未驱逐的字节。触发清除会告诉系统“我现在需要这块空间”,并强制释放这些文件。

## 详情

APFS 维护了多层软可驱逐存储:

- **iCloud 同步文件** 拥有本地副本和云端副本。
- **Time Machine 本地快照**(见专用条目)。
- **macOS 管理的缓存** 在磁盘压力上升时被标记为可驱逐。

访达将可清除字节计入“可用”,但不会显示在“已用”或“空闲”中。它们对 macOS 是空闲,但对老式计算可用空间的应用却是占用。清除会真正释放它们。

MacSense 调用与系统在磁盘压力下使用的相同路径(`diskutil apfs deleteContainer`、`tmutil thinlocalsnapshots`),只是按需触发。无数据丢失 — 每个可清除字节在别处都有另一份副本。
