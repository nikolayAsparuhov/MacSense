# 上次使用日期

macOS 记录的应用启动的最近时刻。从 Spotlight 的 `kMDItemLastUsedDate` 元数据中取得。

## 详情

每当你通过访达、程序坞、Spotlight 或 Launchpad 启动应用时,macOS 都会更新此时间戳。你保留安装但从不打开的应用就在这里积尘 — 正是“未使用”标签页要找的目标。

“未使用”标签页将你的应用按两种方式分组:

- **未使用 ≥ X 天** — 已知最后使用日期早于阈值的应用。最旧的排在前面。
- **从未打开** — 没有 `kMDItemLastUsedDate` 的应用。可能已安装但从未运行过,或其 Spotlight 元数据未被记录。

阈值预设:30 / 60 / 90 / 180 天。你的选择会跨启动持久保存。

点击任意行打开标准的卸载面板 — 与“已安装应用”标签页相同的流程。
