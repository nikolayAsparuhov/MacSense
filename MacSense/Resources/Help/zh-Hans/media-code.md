# 代码

大多数流行语言和配置格式的源文件。有助于发现旧的项目快照、下载的 gist 或占用磁盘的过时仓库克隆。

## 详情

被归为代码的扩展名:`swift`、`tsx`、`ts`、`jsx`、`js`、`mjs`、`py`、`rb`、`go`、`rs`、`java`、`kt`、`cs`、`c`、`cpp`、`cc`、`h`、`hpp`、`sh`、`bash`、`zsh`、`html`、`css`、`scss`、`sass`、`less`、`sql`、`yaml`、`yml`、`json`、`xml`、`toml`、`graphql`、`proto`、`r`、`scala`、`php`。

`node_modules`、`target`、`build` 和其他项目本地产物目录不会单独拆出 — 它们作为父项目内的普通代码/文件出现。清理 → 开发者缓存类别针对的是项目之外的*共享*包缓存。
