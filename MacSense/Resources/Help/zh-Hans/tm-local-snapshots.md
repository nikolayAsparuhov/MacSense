# Time Machine 本地快照

即便备份磁盘未连接,Time Machine 也会在每小时拍摄的磁盘级快照。它们位于内部磁盘上,悄悄占用空间。

## 详情

Time Machine 的现代设计保留滚动的本地快照窗口,让你无需外置驱动器就能恢复近期更改。每个快照都是写时复制引用,因此新建快照成本低 — 但随着你编辑和删除文件,快照会逐渐固定这些字节。

累积的征兆:

- 磁盘感觉满了,但访达显示有空间。
- “可清除”字节很大。
- 大量下载后,删除并未释放空间。

MacSense 调用 `tmutil thinlocalsnapshots /` 按需释放它们。macOS 优先驱逐最旧的快照;基于云端 Time Machine 目标不受影响。重新连接外置 Time Machine 驱动器后,新快照会重新滚入。
