# 登录代理

你登录时 macOS 自动启动的进程。一些是必需的(系统服务、钥匙串助手),另一些是应用伴随服务,你也许不需要它一直运行。

## 详情

登录代理来自三处:

- **系统** — `/System/Library/LaunchAgents` 中由 macOS 提供的代理。MacSense 从不触碰。
- **每个用户** — `~/Library/LaunchAgents` 中的 launchd plist。常由第三方应用安装,用于后台同步、检查更新或菜单栏项。
- **内嵌** — 通过 `SMAppService` 注册(见“内嵌登录项”)。

每用户代理可安全禁用或删除 — 父应用照常运行,只是失去后台行为。如果出现异常,重新启用代理或重新安装应用即可恢复。
