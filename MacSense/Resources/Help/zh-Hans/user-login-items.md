# 用户登录项

你登录 Mac 时自动启动的应用和助手。归你的用户账户所有,因此禁用或删除只影响你的会话。

## 详情

用户登录项来自两处:

- **launchd plist** 位于 `~/Library/LaunchAgents` — 通常由第三方应用安装,用于后台同步、检查更新或菜单栏项。
- **`SMAppService` 注册** 在应用 bundle 内声明(macOS 13+)。MacSense 显示但无法切换 — 请使用系统设置 → 通用 → 登录项。

大多数用户登录项可安全禁用:父应用照常工作,只是没有自动启动行为。如果出现异常,重新启用代理或重新打开应用即可恢复。
