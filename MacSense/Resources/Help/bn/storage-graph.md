# স্টোরেজ গ্রাফ

আপনার ডিস্কের ফোল্ডার-বাই-ফোল্ডার ম্যাপ, যেখানে প্রতিটি আইটেম তার অন-ডিস্ক বরাদ্দ অনুসারে আকার পায়। অনুমান ছাড়াই স্পেস খাচ্ছে কী তা খুঁজে বের করতে দেয়।

## বিস্তারিত

স্টোরেজ বিভাগ `/`-এর অধীনে প্রতিটি ফোল্ডারের একটি ট্রি তৈরি করে, পুনরাবৃত্ত আকার গণনা করে এবং দুটি ভিউ উপস্থাপন করে:

- **Size ট্যাব** — ইন্টারঅ্যাক্টিভ বাবল ম্যাপ। বড় বৃত্ত = বড় ফোল্ডার। প্রবেশের জন্য ক্লিক করুন; উপরের ব্রেডক্রাম্ব আপনার পথ ট্র্যাক করে।
- **Type ট্যাব** — মিডিয়া প্রকার (ভিডিও, অডিও, আর্কাইভ, স্ক্রিনশট…) দ্বারা গোষ্ঠীবদ্ধ ফাইল যাতে আপনি দেখতে পারেন, উদাহরণস্বরূপ, আপনার ডিস্কের ৩০ GB ভিডিও ফাইল।

প্রথম স্ক্যান প্রায় ৩০ সেকেন্ড নেয় কারণ আপনার হোম ফোল্ডারের অধীনে প্রতিটি বাইট ঘুরতে হয়। তারপর MacSense একটি স্ন্যাপশট ডিস্কে ক্যাশ করে যাতে পরবর্তী পরিদর্শন তাৎক্ষণিকভাবে ডেটা দেখায় যখন একটি রিফ্রেশ ব্যাকগ্রাউন্ডে চলে।

গ্রাফ ভিউ থেকে ফাইল কখনও সরানো বা মুছে ফেলা হয় না — এটি কেবল-পঠন পরিদর্শন। আপনি যখন কিছু সত্যিই ট্র্যাশ করতে চান তখন Cleanup বিভাগের ক্যাটাগরি শীট ব্যবহার করুন।
