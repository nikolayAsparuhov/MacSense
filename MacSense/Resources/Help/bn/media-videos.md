# ভিডিও

MacSense আপনার হোম ফোল্ডারের অধীনে যে সমস্ত ভিডিও ফাইল খুঁজে পেয়েছে। সাধারণত Mac-এ একক বৃহত্তম ক্যাটাগরি কারণ ভিডিও বিটরেট অন্য সব কিছুকে ছাড়িয়ে যায়।

## বিস্তারিত

ভিডিও হিসেবে শ্রেণীবদ্ধ এক্সটেনশন: `mp4`, `mov`, `mkv`, `avi`, `webm`, `m4v`, `flv`, `wmv`, `mpeg`, `mpg`, `3gp`, `ts`।

কার্ডটি তাদের অন-ডিস্ক আকারের সাথে শীর্ষ ৫টি বৃহত্তম ভিডিও দেখায়। কার্ডে ক্লিক করলে পূর্ণ তালিকা খোলে, বড় থেকে ছোট সাজানো, যেখানে আপনি পৃথক ফাইলগুলি ট্র্যাশে স্থানান্তর করতে পারেন।

System Library ভিডিও সম্পদ এবং সুরক্ষিত অ্যাপ bundle-এর ভিতরের আইটেম বাদ দেওয়া হয়।
