# সিস্টেম জাঙ্ক

লগ, অস্থায়ী ফাইল এবং ক্র্যাশ রিপোর্ট যা macOS বা ইনস্টল করা অ্যাপগুলি আপনার হোম ফোল্ডারের বাইরে রেখে দেয়। মুছে ফেলা নিরাপদ — সিস্টেম যা প্রয়োজন তা পুনরায় তৈরি করে।

## বিস্তারিত

তিনটি বালতি:

- **ডায়াগনস্টিক রিপোর্ট** `/Library/Logs` এবং `/var/log`-এ। macOS এগুলি স্বয়ংক্রিয়ভাবে রোটেট করে।
- **ক্র্যাশ রিপোর্ট** `/Library/Application Support/CrashReporter`-এর অধীনে। ক্র্যাশের ঠিক পরে কাজে লাগে, মাস পরে অর্থহীন।
- **ইনস্টলের অবশিষ্ট** প্যাকেজ ইনস্টলার এবং অ্যাপ আপডেট দ্বারা রেখে যাওয়া।

MacSense সবকিছু ট্র্যাশে পাঠিয়ে দেয়। এখানে আপনার ডকুমেন্ট বা পছন্দ নেই — শুধু সিস্টেম-উৎপন্ন আর্টিফ্যাক্ট।
