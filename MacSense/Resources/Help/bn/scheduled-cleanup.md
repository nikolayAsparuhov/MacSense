# নির্ধারিত পরিষ্কার

একটি ঐচ্ছিক পুনরাবৃত্ত স্ক্যান যা দৈনিক, সাপ্তাহিক বা মাসিক ছন্দে ব্যাকগ্রাউন্ডে চলে এবং সারাংশ নোটিফিকেশন পোস্ট করে।

## বিস্তারিত

সক্ষম হলে, MacSense `NSBackgroundActivityScheduler` ব্যবহার করে — macOS-এর শক্তি-বান্ধব টাস্ক API — আপনার চিহ্নিত ক্যাটাগরিগুলির উপর Smart Scan চালাতে। ফলাফল একক নোটিফিকেশন হিসেবে আসে:

> ৪টি ক্যাটাগরিতে ৪.৭ GB পুনরুদ্ধারযোগ্য পাওয়া গেছে। পর্যালোচনার জন্য MacSense খুলুন।

নোটিফিকেশনে ট্যাপ MacSense-এর Cleanup বিভাগ খোলে।

গুরুত্বপূর্ণ সীমাবদ্ধতা:

- **কিছুই স্বয়ংক্রিয়ভাবে মুছে না।** শিডিউল নোটিফাই করে; আপনি সিদ্ধান্ত নেন কী (যদি কিছু) পরিষ্কার করবেন।
- **MacSense খোলা বা সম্প্রতি সক্রিয় থাকাকালীন শিডিউল চলে।** macOS ব্যাকগ্রাউন্ড টাস্ক বিলম্বিত করতে পারে। কোনো LaunchAgent বা ডেমন নেই — অ্যাপ পুরোপুরি বন্ধ করা পরবর্তী লঞ্চ পর্যন্ত শিডিউল থামিয়ে দেয়।

প্রথম লঞ্চে নোটিফিকেশন অনুমতি একবার চাওয়া হয়। আপনি আগে অস্বীকার করলে, Schedule বিভাগ System Settings-এর শর্টকাট সহ ব্যানার দেখায়।
