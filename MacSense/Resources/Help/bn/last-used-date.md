# শেষ ব্যবহারের তারিখ

অ্যাপ চালু হওয়ার সবচেয়ে সাম্প্রতিক মুহূর্ত যা macOS রেকর্ড করেছে। Spotlight-এর `kMDItemLastUsedDate` মেটাডেটা থেকে নেওয়া।

## বিস্তারিত

আপনি যখনই Finder, Dock, Spotlight, বা Launchpad-এর মাধ্যমে অ্যাপ চালু করেন তখনই macOS এই টাইমস্ট্যাম্প আপডেট করে। আপনি ইনস্টল রাখা কিন্তু কখনও না খোলা অ্যাপগুলি এখানে ধুলো জমায় — ঠিক সেই প্রার্থী যাদেরকে Unused ট্যাব সামনে আনতে চায়।

Unused ট্যাব আপনার অ্যাপগুলিকে দুটি উপায়ে গোষ্ঠীবদ্ধ করে:

- **X দিনের জন্য অব্যবহৃত** — সীমার চেয়ে পুরানো জানা শেষ ব্যবহারের তারিখ সহ অ্যাপ। প্রাচীনতম প্রথমে সাজানো।
- **কখনও খোলা হয়নি** — `kMDItemLastUsedDate` ছাড়া অ্যাপ। ইনস্টল করা থাকতে পারে কিন্তু কখনও চালানো হয়নি, বা তাদের Spotlight মেটাডেটা রেকর্ড করা হয়নি।

থ্রেশহোল্ড প্রিসেট: ৩০ / ৬০ / ৯০ / ১৮০ দিন। আপনার পছন্দ লঞ্চের মধ্যে স্থায়ী থাকে।

যেকোনো সারিতে ট্যাপ করলে স্ট্যান্ডার্ড আনইনস্টল শীট খোলে — Installed Apps ট্যাবের মতোই প্রবাহ।
