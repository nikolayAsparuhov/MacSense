# কোড

বেশিরভাগ জনপ্রিয় ভাষা এবং কনফিগ ফরম্যাটে সোর্স ফাইল। পুরানো প্রজেক্ট স্ন্যাপশট, ডাউনলোড করা gist, বা ডিস্ক খাচ্ছে এমন বাসি রেপো ক্লোন সনাক্ত করতে দরকারী।

## বিস্তারিত

কোড হিসেবে শ্রেণীবদ্ধ এক্সটেনশন: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`।

`node_modules`, `target`, `build`, এবং অন্যান্য প্রজেক্ট-স্থানীয় আর্টিফ্যাক্ট ডিরেক্টরি আলাদা করা হয় না — এগুলি তাদের মূল প্রজেক্টের ভিতরে সাধারণ কোড/ফাইল হিসেবে দেখা যায়। Cleanup → Developer Caches ক্যাটাগরি আপনার প্রজেক্টের বাইরে *শেয়ার্ড* প্যাকেজ ক্যাশকে লক্ষ্য করে।
