# ইউজার লগইন আইটেম

অ্যাপ এবং হেল্পার যা আপনি Mac-এ লগ ইন করলে স্বয়ংক্রিয়ভাবে শুরু হয়। আপনার ইউজার অ্যাকাউন্টের মালিকানাধীন, তাই নিষ্ক্রিয় বা সরানো শুধু আপনার সেশন প্রভাবিত করে।

## বিস্তারিত

ইউজার লগইন আইটেম দুটি জায়গা থেকে আসে:

- **launchd plist** `~/Library/LaunchAgents`-এ — সাধারণত তৃতীয়-পক্ষ অ্যাপ দ্বারা ব্যাকগ্রাউন্ড সিঙ্ক, আপডেট চেক, বা মেনু-বার আইটেম প্রদানের জন্য ইনস্টল।
- **`SMAppService` নিবন্ধন** অ্যাপ bundle-এর ভিতরে ঘোষিত (macOS 13+)। MacSense দেখায় কিন্তু টগল করতে পারে না — System Settings → General → Login Items ব্যবহার করুন।

বেশিরভাগ ইউজার লগইন আইটেম নিরাপদে নিষ্ক্রিয় করা যায়: মূল অ্যাপ চলতে থাকে, শুধু অটো-স্টার্ট আচরণ ছাড়া। কিছু ভুল আচরণ শুরু করলে, এজেন্টকে পুনরায় সক্ষম করা বা অ্যাপ পুনরায় খোলা পুনরুদ্ধার করে।
