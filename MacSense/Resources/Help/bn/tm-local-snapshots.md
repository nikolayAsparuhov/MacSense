# Time Machine স্থানীয় স্ন্যাপশট

ঘণ্টায় ঘণ্টায় ডিস্ক-স্তরের স্ন্যাপশট যা Time Machine আপনার ব্যাকআপ ড্রাইভ সংযুক্ত না থাকলেও নেয়। এগুলি আপনার অভ্যন্তরীণ ড্রাইভে থাকে এবং নীরবে স্পেস খায়।

## বিস্তারিত

Time Machine স্থানীয় স্ন্যাপশটের একটি রোলিং উইন্ডো রাখে যাতে আপনি বাহ্যিক ড্রাইভ ছাড়াই সাম্প্রতিক পরিবর্তন পুনরুদ্ধার করতে পারেন। প্রতিটি স্ন্যাপশট copy-on-write রেফারেন্স, তাই নতুন স্ন্যাপশট সস্তা — কিন্তু আপনি যখন সম্পাদনা ও মুছেন, স্ন্যাপশট সেই বাইটগুলিকে জায়গায় আটকে রাখে।

জমার লক্ষণ:

- ডিস্ক ভর্তি মনে হয় কিন্তু Finder মুক্ত স্পেস দেখায়।
- "পার্জেবল" বাইট বড়।
- বড় ডাউনলোডের পর সেটি মুছলে স্পেস মুক্ত হয় না।

MacSense `tmutil thinlocalsnapshots /` চালিয়ে চাহিদা অনুযায়ী মুক্ত করে। macOS প্রথমে সবচেয়ে পুরানো সরায়; বাহ্যিক Time Machine ড্রাইভ ব্যাকআপ অপ্রভাবিত। আপনার বাহ্যিক ড্রাইভ পুনরায় সংযুক্ত হলে নতুন স্ন্যাপশট ফিরে আসে।
