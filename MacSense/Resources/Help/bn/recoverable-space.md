# পুনরুদ্ধারযোগ্য স্পেস

বর্তমান Smart Scan-এর প্রতিটি ক্যাটাগরিতে MacSense আপনাকে যা ফিরিয়ে দিতে পারে তার মোট বাইট অনুমান।

## বিস্তারিত

Cleanup hero-তে সংখ্যাটি এদের যোগফল:

- সিস্টেম জাঙ্ক
- ইউজার ক্যাশ
- ট্র্যাশ
- পার্জেবল স্পেস (Time Machine স্থানীয় স্ন্যাপশট + iCloud উচ্ছেদযোগ্য ফাইল)
- ডেভেলপার ক্যাশ

স্ক্যান অ-ধ্বংসাত্মক — যতক্ষণ না আপনি কোনো ক্যাটাগরিতে Clean ক্লিক করেন, কিছুই সরানো হয় না। অনুমান ডিস্কে বরাদ্দ আকার ব্যবহার করে, যা macOS "Get Info"-তে ব্যবহার করে।

সংখ্যাগুলি সময়ের সাথে কিছুটা কমে কারণ macOS লগ রোটেট করতে থাকে, ক্যাশ সরায় এবং নতুন ফাইল লেখে। Smart Scan পুনরায় চালালে অনুমান নতুন হয়।
