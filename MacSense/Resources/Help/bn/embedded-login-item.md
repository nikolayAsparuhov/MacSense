# এম্বেডেড লগইন আইটেম

`SMAppService` (macOS 13+) এর মাধ্যমে অ্যাপ নিজেই নিবন্ধিত একটি লগইন আইটেম। তৃতীয়-পক্ষ টুল — MacSense সহ — নিরাপত্তার কারণে এগুলিকে নিষ্ক্রিয়, পরিবর্তন বা মুছে ফেলতে পারে না।

## বিস্তারিত

পুরানো লগইন আইটেম API প্রতিস্থাপন করতে Apple `SMAppService` চালু করেছে। সুবিধা:

- অ্যাপগুলি নিজেদের bundle থেকে নিজেকে লগইন এজেন্ট হিসেবে নিবন্ধিত করে।
- macOS নিশ্চিত করে যে অ্যাপের বাইরে কেউ নিবন্ধন পরিবর্তন করতে পারে না।
- ব্যবহারকারী System Settings এর মাধ্যমে পূর্ণ নিয়ন্ত্রণ রাখেন।

আপস: MacSense-এর মতো টুল এই নিবন্ধনগুলি দেখাতে পারে কিন্তু টগল করতে পারে না। "Disable" ক্রিয়াটি সঠিক প্যানে **System Settings → General → Login Items** খোলে যাতে আপনি নিজেই সুইচ ফ্লিপ করতে পারেন।

পুরানো API (LSSharedFileList, `~/Library/LaunchAgents`-এ launchd plist) এর মাধ্যমে নিবন্ধিত পুরানো লগইন আইটেম MacSense থেকে পরিচালনাযোগ্য থাকে।
