# Other

Files that don't match any of the named media buckets — caches, app data, partial downloads, extension-less files, and proprietary formats.

## Details

This is the catch-all bucket. A large "Other" total often points to:

- App support folders (`~/Library/Application Support/...`).
- Partial downloads with `.part` / `.crdownload` extensions.
- Disk images mounted from `.dmg` files.
- Sandbox containers and group containers.

Investigate large Other entries before deleting — some belong to apps you actively use.
