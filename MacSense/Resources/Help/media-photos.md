# Photos

Image files across raster, RAW, and modern Apple formats. Photo libraries can climb into the tens of gigabytes once HEIC bursts and RAW files accumulate.

## Details

Extensions classified as photos: `jpg`, `jpeg`, `png`, `heic`, `heif`, `gif`, `bmp`, `tiff`, `tif`, `webp`, plus RAW formats `raw`, `cr2`, `cr3`, `nef`, `dng`, `arw`, `orf`.

If you use the Photos app, the Library bundle counts as a single archive — MacSense doesn't open it. Loose photos in `~/Pictures`, Downloads, and Desktop are surfaced directly.
