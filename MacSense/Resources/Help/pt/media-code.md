# Código

Arquivos-fonte na maioria das linguagens populares e formatos de configuração. Útil para detectar snapshots de projetos antigos, gists baixados ou clones de repositórios obsoletos consumindo disco.

## Detalhes

Extensões classificadas como código: `swift`, `tsx`, `ts`, `jsx`, `js`, `mjs`, `py`, `rb`, `go`, `rs`, `java`, `kt`, `cs`, `c`, `cpp`, `cc`, `h`, `hpp`, `sh`, `bash`, `zsh`, `html`, `css`, `scss`, `sass`, `less`, `sql`, `yaml`, `yml`, `json`, `xml`, `toml`, `graphql`, `proto`, `r`, `scala`, `php`.

`node_modules`, `target`, `build` e outros diretórios de artefatos locais não são separados — aparecem como código/arquivos comuns dentro do projeto pai. A categoria Limpeza → Caches de Desenvolvimento mira nos caches *compartilhados* fora dos seus projetos.
