# Recoverable Space

Total bytes MacSense estimates it can return to you across every category of the current Smart Scan.

## Details

The number on the Cleanup hero is the sum of:

- System Junk
- User Cache
- Trash Bins
- Purgeable Space (Time Machine local snapshots + iCloud-evictable files)
- Developer Caches

A scan is non-destructive — nothing is removed until you click Clean on a category. The recoverable estimate uses on-disk allocated size, the same measure macOS uses in "Get Info", so the bytes you see are the bytes you'd see freed.

Numbers shrink slightly as macOS continuously rotates logs, evicts caches, and writes new files. Re-running Smart Scan refreshes the estimate.
